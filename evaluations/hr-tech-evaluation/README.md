# HR tech evaluation starter pack

This pack is tailored to the migration from **SAP SuccessFactors Recruiting** (within the
broader SuccessFactors HRIS/EC platform) to **SmartRecruiters**.

It is intentionally evidence-led: no capability, price, compliance position, or
implementation promise has been invented.

## Working assumptions

The current problem is a replacement decision for the recruiting system, not a generic ATS
buy. The pack assumes:

- The incumbent is SAP SuccessFactors Recruiting, which sits inside the broader
  SuccessFactors HRIS / Employee Central environment.
- The target is SmartRecruiters unless an alternative vendor is later added to the shortlist.
- The shortlist will contain up to three vendors, referred to as Vendor A, Vendor B, and
  Vendor C until the real names are supplied.
- The organisation has an HRIS, identity provider, calendar/email platform, background
  check provider, and BI or data warehouse that the ATS must connect to.
- Synthetic or anonymised data will be used in demos and trials.

The evaluation should still be treated as a disciplined procurement exercise: the weights
must remain fixed after the first demo unless a genuinely new requirement is added and all
vendors are re-scored.

## Inputs needed to finalise

1. The observable problem this purchase must fix and its current baseline.
2. Category confirmation if this is not an ATS.
3. Current stack, headcount, hires per year, user counts, jurisdictions, and growth plan.
4. Vendors already in view, incumbent notice deadline, budget band, and decision date.
5. Named evaluators, daily users, veto holders, and owners for security, legal, finance, and
   data migration.

Contract interpretation, data protection advice, security clearance, and employment-law
determinations remain with the relevant specialists.
